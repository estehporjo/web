# Es Teh Porjo Landing Page V7

V7 mempertahankan struktur dan halaman V6, dengan revisi visual beranda sesuai referensi terbaru:

- Badge hero kiri luar outlet menggunakan aset PNG transparan `badge-sekarang-juga.png`.
- Badge `100% GULA ASLI` menggunakan aset PNG transparan `badge-gula-asli.png` dan ditempatkan di tengah sisi kanan foto outlet, keluar dari frame sehingga tidak menutupi foto.
- Ikon `Teh Asli` dibuat ulang dengan SVG bergaya daun teh yang lebih sederhana dan bersih.
- Ditambahkan/dirapikan feature row: Teh Asli, Segar, 100% Gula Asli, Harga.
- Badge `100% GULA ASLI` pada halaman Tentang juga menggunakan PNG yang sama dan ditempatkan di tengah sisi kanan foto, di luar foto.
- Menu, Promo, Stand, Lokasi, Kontak, spesifikasi gelas, animasi reveal, page wipe, parallax, dan dekorasi daun tetap dipertahankan dari V6.
